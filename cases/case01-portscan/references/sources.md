## CIC-IDS2017

- 자료명: Intrusion detection evaluation dataset (CIC-IDS2017)
- 기관/저자: Canadian Institute for Cybersecurity
- URL: <https://www.unb.ca/cic/datasets/ids-2017.html>
- 확인일: 2026-09-21
- 사용 목적: CIC-IDS2017 데이터셋의 출처와 `Friday-WorkingHours.pcap` 분석 대상 확인
- 메모: 이 문서에서는 데이터셋 페이지를 출처로만 사용했습니다. 독립적인 데이터셋 라벨 검증 결과를 별도로 주장하지 않습니다.

## Wireshark

- 자료명: Wireshark User’s Guide
- 기관/저자: Wireshark Foundation
- URL: <https://www.wireshark.org/docs/wsug_html/>
- 확인일: 2026-09-21
- 사용 목적: Display Filter의 사용 방법과 필드·논리식 기반 필터 표현 확인
- 메모: Case의 실제 필터 결과와 스크린샷은 저장소의 `evidence/screenshots/`에 기록했습니다.

## MITRE ATT&CK

- 자료명: Network Service Discovery, Technique T1046
- 기관/저자: MITRE ATT&CK
- URL: <https://attack.mitre.org/techniques/T1046/>
- 페이지 표기 버전: 3.2
- 확인일: 2026-09-21
- 사용 목적: 관찰된 포트·네트워크 서비스 탐색 행위를 T1046으로 매핑
- 메모: 매핑은 관찰된 행위의 성격을 설명하기 위한 것이며, 악성 의도나 후속 침해 여부를 의미하지 않습니다.
